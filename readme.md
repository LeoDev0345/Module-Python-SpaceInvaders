# Space Invaders

Un jeu Space Invaders développé en Python.

## Comment y jouer ? (Installation ultra simple)

1. **Installer Python** : Assurez-vous d'avoir Python 3 installé sur votre ordinateur.
2. **Installer les dépendances** : Ouvrez un terminal dans ce dossier et tapez :
   ```bash
   pip install -r requirements.txt
   ```
3. **Lancer le jeu** :
   ```bash
   python3 ./code/main.py
   ```
